# 回診アシスト

病棟回診とカルテ記載を補助する個人用のWebアプリ（PWA）です。

- ① 毎朝チェック／② 経過評価／③ 予定入力／④ スケジュール・経過グラフ
- 入力データは使用している端末のブラウザ内にのみ保存され、外部には送信されません。
- 氏名・患者IDなど個人を特定できる情報は入力しないでください。

## 使い方（Android）
1. Chromeで公開ページを開く
2. メニュー「︙」→「アプリをインストール」（または「ホーム画面に追加」）
3. ホーム画面のアイコンから起動

本ツールは記録補助を目的とした概算計算を含みます。診断・治療方針は臨床所見に基づき医師が判断してください。
